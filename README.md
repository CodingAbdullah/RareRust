# Deep Dive into Practical Rust

This repository contains all the detailed solutions (created solely by myself) for a Rust curriculum outlined by **[RareCode.ai](https://rarecode.ai)**.

> **Note:** This repo only contains the *solutions*. The lesson prompts, explanations, and interactive exercises themselves are live on RareCode.ai. You will need to **sign up and subscribe** there to access the full lessons.

If you want the reasoning behind why this curriculum is shaped the way it is (and a broader case for learning Rust in the first place), read the companion article:

📄 [**Learn Rust and Start Building Real Developer Tools**](https://medium.com/stackademic/learn-rust-and-start-building-real-developer-tools-ddc198cd844f) — on Medium/Stackademic
